# RoomWala Booking Pipeline & Life-Cycle

## 1. Flow
1. **Search & Discovery**: Verified listings only.
2. **Date Selection**: Range picker with conflict check.
3. **10-Minute Hold**: Atomic slot lock.
4. **Verification**: 18+ eligibility.
5. **Confirmation**: Keyless PIN generated (`PIN-xxxx`) and WhatsApp pass sent.
